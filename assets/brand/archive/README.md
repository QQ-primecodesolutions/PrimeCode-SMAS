# Archived logo: do not use

`logo-helmet.png` is PrimeCode's original logo (until October 2026): a robot helmet inside a
monitor. The helmet resembled a Transformers character, which is Hasbro's intellectual property,
so the logo risked takedowns and couldn't be registered as our own trademark. It was retired before
the October 2026 comeback post.

The current logo is built by `scripts/brand/build_logo.py` (`assets/brand/logo.svg` and friends).
This file is kept only as a record. Don't use it in slides, the website, social profiles or print.
